# 月下占卜

> 在月光下，聽見自己的答案

繁體中文塔羅占卜網站，做成 PWA。免登入，可加入 iPhone 主畫面，完成一次離線準備後即可離線占卜。以 iPhone Safari 單手操作為優先，桌面瀏覽器也能使用。

## 功能

- **兩種三張牌牌陣**
  - 三張牌指引：現況／阻礙／建議，主題可選感情、工作、財運、綜合
  - 感情關係牌陣：我的感受與期待／目前的互動模式／下一步建議，情境可選曖昧中、交往中、分開後，也可以略過
- **抽牌**：洗牌動畫之後，可用「滑動手選」或「快速抽三張」。如果已經手選了部分牌再按快速抽牌，會先跳出提示確認。同一局不會抽到重複的牌。三張都放好後要依序點擊翻牌。
- **逆位**：插畫旋轉 180 度，牌名、牌位和「逆位」標籤維持正向。翻牌畫面、結果頁、歷史紀錄和 PNG 結果卡都是同樣的呈現方式。
- **解讀**：內建 156 筆正逆位牌義，再依牌位、主題和感情情境組出解讀（不需連網）。結果頁依序顯示整體摘要、可展開的逐張解讀，以及一個給自己的提問。
- **結果卡**：1080×1920 的直式 PNG，在裝置上繪製，提供「酒紅古金」和「羊皮紙米白」兩款配色。選過的配色會被記住。可以下載，也可以用系統分享選單傳到 LINE。卡片上不會出現提問和感情情境。
- **歷史紀錄**：按「儲存結果」才會建立紀錄。可依全部／感情／工作／財運／綜合篩選，由新到舊排列，每筆可以查看、重新下載結果卡或刪除。
- **PWA**：包含 Manifest、主畫面圖示和 Service Worker。全部 97 個必要檔案都確認已快取後，首頁才會顯示「已可離線使用」；快取失敗時可以重試。有新版本時會提示重新載入，更新後紀錄和配色都會保留。
- **減少動態效果**：系統開啟「減少動態效果」時，翻牌改用淡入，不做 3D 翻轉。

## 隱私

提問、感情情境、解讀和配色只存在目前裝置的 `localStorage`，不會上傳，也不會寫進網址。「分享網站」只分享公開首頁的網址。

**iPhone 注意事項**：Safari 和主畫面版本的儲存空間是分開的，兩邊的紀錄和配色不會互通。這點在首頁和歷史紀錄頁都有說明。

## 本機執行

```bash
python3 -m http.server 8123
```

接著開啟 http://localhost:8123/ 。Service Worker 只能在 HTTPS 或 localhost 上運作。

修改任何網站檔案後，都要重新產生快取清單（版本號會跟著改變，已安裝的使用者就會看到更新提示）：

```bash
node tools/build-manifest.mjs
```

重新產生牌圖或圖示：

```bash
node tools/gen-cards.mjs
```

```bash
node tools/render-icons.cjs
```

## 測試

先啟動上方的本機伺服器，再執行：

```bash
node tests/e2e.cjs
```

```bash
node tests/update.cjs
```

## 部署（HTTPS）

這是純靜態網站，不需要建置步驟，任何支援 HTTPS 的靜態主機都可以。

### GitHub Pages（從分支部署）

1. 到 GitHub 儲存庫的 **Settings → Pages**，把 **Source** 設為 **Deploy from a branch**。
2. Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**。
3. 之後每次推送到 `main`，GitHub 會自動重新發布。網址通常是 `https://<帳號>.github.io/<儲存庫>/`。

根目錄的 `.nojekyll` 會讓 GitHub 跳過 Jekyll 處理，把檔案原樣發布，請保留這個檔案。

**修改網站後，推送前一定要先執行 `node tools/build-manifest.mjs`。** 這會更新快取版本號，已安裝的使用者才會收到「有新版本」的提示。沒更新的話，他們會一直使用舊的快取。

網站全部使用相對路徑，放在子目錄下也能正常運作。

### Netlify／Cloudflare Pages

建置指令留空，發布目錄填專案根目錄 `/` 即可。

### iPhone 飛航模式驗收步驟

1. 用 iPhone Safari 開啟部署後的 HTTPS 網址。
2. 點分享 →「加入主畫面」，確認名稱是「月下占卜」→ 新增。
3. **在連線狀態下**從主畫面開啟，等首頁顯示「● 已可離線使用」。
4. 從多工畫面把 App 完全滑掉關閉。
5. 開啟控制中心的**飛航模式**，並確認 Wi-Fi 也已關閉。
6. 從主畫面重新開啟「月下占卜」。
7. 三張牌指引：選「財運」→ 洗牌 → 用滑動手選兩張 → 按快速抽三張 → 確認 → 依序翻三張 → 看解讀 → 儲存結果。
8. 感情關係牌陣：選「曖昧中」→ 用快速抽牌 → 翻牌 → 儲存結果。
9. 進入歷史紀錄，依序切換全部／感情／工作／財運／綜合，確認篩選結果正確，沒有紀錄的主題會顯示空白提示。
10. 打開其中一筆紀錄 → 預覽結果卡 → 分別切換兩款配色並各下載一次 PNG（或長按圖片存到照片）。
11. 刪除一筆紀錄，確認列表隨即更新。
12. 關閉飛航模式，重新開啟 App，確認紀錄和配色都還在。
